# Проверка незавершённого цикла feeder — 28 октября 2026

`scripts/inspect_incomplete_feeder.py` через отдельный read-only модуль
`feeder_incomplete_inspection.py` проверяет одну исходную регистрацию managed
feeder и один incomplete cycle. Он захватывает уже существующую локальную lease,
проверяет текущие runtime pins и исходный plan, contiguous порядок stage receipts,
самосогласованность сохранённых наблюдений BTC/ETH и SHA файлов в начале и конце
проверки. Незаписанная стадия считается неизвестной: ни повтор, ни исправление
`complete.json`, ни удаление не разрешаются. Для двух mandatory reference stages
проверяется особенность исходного control flow: вторая может запускаться даже
после неуспеха первой. Новых запросов к бирже/БД инструмент не делает.

В частичном цикле нет подписанного `complete.json` и полный stdout стадий не
сохранён: проверка сверяет retained self-consistency, а не доказывает внешнюю
подлинность всех файлов или фактический эффект sync в БД. Для доказанного
reconciliation нужны исходные row versions, независимые SQL/REST observations и
оценка конкурирующих writers. После этого нужен отдельный проверенный recovery;
этот инструмент не обходит guard установленного feeder.
